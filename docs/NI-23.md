# NI-23 Kortų katalogo importas

`card-updater` startuodamas ir kartą per parą tikrina „Scryfall“ masinių
duomenų sąrašą. Jis pasirenka `oracle_cards` rinkmeną (dabartinis
`jsonl_download_uri` arba ankstesnis `download_uri`) ir atsisiunčia ją tik
pirmajam įkėlimui, pasikeitus `updated_at` arba pasikeitus modelio versijai.
Rankinis paleidimas naudoja tą pačią užduotį ir patikrą:

```sh
docker compose exec -T card-updater python -m app.catalog_update
docker compose logs card-updater
```

„Qdrant“ įrašo ID yra `Oracle ID`. Įraše saugomi pavadinimas,
`name_keys`, tipas, manos kaina ir vertė, spalvos, taisyklių tekstas bei
paveikslėlio nuoroda. Kelių pusių kortų duomenys laikomi `card_faces`.
Importuojant sąrašą pirmenybė teikiama pilnam kortos pavadinimui,
jei jis sutampa su kitos kortos pirmos pusės slapyvardžiu.
Naudotojų ir kaladžių lentelės lieka PostgreSQL.

Katalogas paruošiamas naujoje kolekcijoje. Tik įkėlus visus įrašus ir
`name_keys` indeksą perjungiamas programos naudojamas `cards__current` aliasas.
Iki perjungimo užklausos skaito seną kolekciją. Ankstesnis katalogas
išlaikomas, o senesnės šio importuotojo kolekcijos valomos automatiškai.
Pirmą kartą įjungus NI-23, atnaujintojas perima ankstesnę `cards`
kolekciją arba aliasą. Ankstesnius duomenis galima skaityti ir vykstant
pirmajam atnaujinimui.
Jei kortos nebėra naujoje rinkmenoje, jos ankstesnis įrašas perkeliamas,
kad išliktų pasiekiama kaladėse. Žurnale fiksuojami nauji, pakeisti ir
tokiu būdu išsaugoti įrašai, rinkmenos versija bei klaidos.

Šiame etape importuojami metaduomenys. NI-25 galės perduoti `CardEncoder`
su modelio versija ir Qdrant vektorių konfigūracija. Kai versija pasikeis,
importuotojas iš naujo apskaičiuos visus vektorius, net jei rinkmena ta pati.
Esant tai pačiai versijai, nepakeistų kortų vektoriai perkeliami iš ankstesnio
katalogo. Nepavykus apskaičiuoti vektorių, aliasas neperjungiamas.
